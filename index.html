HAVE QUESTIONS?

Frequently asked questions.

Helpful information about using this demonstration website.

How can I request an appointment?

Go to the appointment section, fill in the required fields and submit the form. The current demo only displays a confirmation on the page.

Can I choose a medical department?

Yes. Choose a department in the appointment form. Doctor profile links can also select a matching department.

Where can I find the clinic's contact details?

Visit the contact section. Verified clinic details must be added before the website is used as a real clinic website.

Does this website provide medical advice?

No. The website is an informational demonstration and is not a substitute for professional medical assessment.
